# Computational Future Intelligence

Computational Future Intelligence is an early-stage research and software project exploring how institutions can connect events, source evidence and uncertainty to decisions in equity markets and prediction markets.

The first executable component is an offline prototype for potential indirect portfolio exposures. It demonstrates a narrow, auditable workflow with synthetic data. Real document processing, trained NLP models, APIs and a customer interface remain future engineering work.

**[Open the Python research prototype](research/prototype_0/README.md)**

We prioritize accurate source attribution, point-in-time reconstruction, reproducible evaluations and explicit uncertainty over plausible but unsupported explanations. The shared evidence foundation is designed to serve both financial markets without treating the two products as identical.

The examples in this repository are fictional unless explicitly identified as independently sourced. Nothing here constitutes investment advice or a verified risk alert.
